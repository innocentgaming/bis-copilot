# BIS Quality / Compliance Copilot — Controlled Failure Injection Matrix

**Phase 8 Fault Tolerance & Degradation Verification**  
This document outlines the 10 failure injection scenarios, simulated fault triggers, expected behaviors, and verified system outcomes.

---

## Controlled Failure Injection Scenarios

| # | Injected Failure Scenario | Fault Trigger / Injection Method | Expected System Behavior | Verified Outcome & Safety Mechanism | Status |
| :- | :--- | :--- | :--- | :--- | :---: |
| **A** | **PostgreSQL Unavailable** | Terminate PostgreSQL container or supply invalid port `5433` in `DATABASE_URL`. | `/health` responds with status `degraded`; `/ready` returns HTTP 503; Database API routes return clean JSON error without unhandled tracebacks; Frontend displays helpful offline badge. | Verified. `check_sync_connection()` detects refusal; routes return HTTP 503 Service Unavailable or skip gracefully without crashing ASGI server. | **[PASS]** |
| **B** | **Embedding Model Unavailable** | Mock missing PyTorch/HuggingFace cache directory or trigger `ModelNotFoundError`. | Graceful fallback to `DeterministicEmbeddingProvider` (hash-derived normalized pseudo-embeddings); logs warning; system continues serving search requests via lexical FTS. | Verified. `backend/app/ingestion/embeddings.py` encapsulates model loading in try/except, seamlessly falling back to deterministic vectors. | **[PASS]** |
| **C** | **Cross-Encoder Reranker Unavailable** | Simulate `RerankingError` or `FlashRank` initialization timeout. | Pipeline falls back to pure Reciprocal Rank Fusion (RRF) hybrid score ranking; emits warning log; returns un-reranked top-K results without dropping valid chunks. | Verified. `backend/app/retrieval/reranker.py` `NoOpReranker` logs warning and returns candidates sorted by input RRF relevance. | **[PASS]** |
| **D** | **LLM Provider Unavailable / Rate-Limited** | Trigger external LLM timeout, HTTP 429 quota exhaustion, or supply invalid API key. | Controlled generation failure; no fabricated or hallucinated fallback answer is generated; response sets `insufficient_evidence: true` or returns HTTP 502 with retry header. | Verified. `backend/app/generation/llm_provider.py` and `deterministic_provider.py` intercept failures and emit structured fallback JSON without hallucinations. | **[PASS]** |
| **E** | **Server-Sent Events (SSE) Stream Disconnect** | Force-close client TCP socket mid-stream during token generation. | Backend detects `ClientDisconnect` exception, terminates generator loop immediately, and frees database session; frontend retains partial answer without UI crash. | Verified. `backend/app/generation/streaming.py` checks `request.is_disconnected()` in stream loop, avoiding orphan generator threads. | **[PASS]** |
| **F** | **Invalid / Expired JWT Token** | Send HTTP request with forged signature or token expired in 1970. | HTTP 401 Unauthorized with header `WWW-Authenticate: Bearer error="invalid_token"`. | Verified. Handled deterministically by `backend/app/core/security.py` using `jwt.decode` with signature and expiry validation. | **[PASS]** |
| **G** | **Unauthorized Admin Request** | Send request to `/api/v1/admin/*` or `/api/v1/documents/ingest` with standard `auditor` or `user` role token. | HTTP 403 Forbidden with `{ "detail": "Admin privileges required" }`. | Verified. Fast-fail RBAC enforced by `require_admin` dependency in `backend/app/api/deps.py`. | **[PASS]** |
| **H** | **Invalid Document Format / Malicious File** | Upload `.exe`, `.sh`, or binary file renamed to `.pdf` with invalid magic bytes. | Ingestion rejected with HTTP 400 or HTTP 422; validation error logged; file unlinked from temporary storage. | Verified. `backend/app/ingestion/validation.py` validates PDF magic header `%PDF-` and MIME type `application/pdf`. | **[PASS]** |
| **I** | **Duplicate Document Upload** | Upload existing standard PDF with identical SHA-256 hash. | System identifies duplicate checksum; suppresses redundant chunk re-indexing or returns HTTP 409 Conflict / existing document ID. | Verified. `backend/app/ingestion/checksum.py` computes SHA-256 and checks database uniqueness constraint. | **[PASS]** |
| **J** | **Empty Retrieval / Unsupported Query** | Query standard or topic absent from database (e.g. "What is bullet train speed limit in IS 99999?"). | Safe refusal response; `insufficient_evidence: true`; 0 fabricated clauses; 0 hallucinated citations; confidence calibrated < 0.20. | Verified. `audit_grounding.py` verified 100% refusal accuracy on negative and out-of-domain scenarios. | **[PASS]** |
